# プロダクト名
アルティメット将棋

## チーム名

チーム28 ゲーム好き一般人

## プロダクト説明

盤面をひっくり返す、超自由なゲーム体験<br>
駒を取ることによるポイント加算、ポイントによるスキル発動、新駒やギミックを追加予定<br>
ゲーム出展型イベント『大阪ゲームダンジョン2』（12/26）出展予定
